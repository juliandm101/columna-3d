# Columna en 3D

Visor 3D de una columna lumbar y pelvis reconstruida a partir de una tomografía (322 cortes, filtro óseo) y validada con resonancia magnética (T1, T2, STIR).

- Visor: `index.html` (Three.js, todo el modelo va embebido en el archivo).
- Rotar, hacer zoom, ocultar huesos, cortes sagital/coronal/axial, modos de color por hueso, densidad y validación.

Es una reconstrucción automática con fines ilustrativos. No es un informe médico.
